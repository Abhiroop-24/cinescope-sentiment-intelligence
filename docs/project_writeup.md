# CINESCOPE — two-page write-up source

## Problem and motivation

Movie reviews contain useful but noisy language about audience sentiment.
CINESCOPE studies binary document-level sentiment classification and turns the
result into an explainable demo for a live evaluation.

## Dataset

We use the official IMDb Large Movie Review Dataset: 25,000 labeled training
reviews and 25,000 labeled test reviews, balanced across positive and negative
classes. The paper describes deriving labels from rating thresholds, but the
public benchmark does not expose each original rating; therefore our work is a
reproducible reproduction attempt rather than an exact replication.

## Approach and implementation

Text is lowercased, tokenized, stripped of punctuation, numbers, and common
stopwords, and represented by normalized TF-IDF unigrams. A deterministic
sparse logistic regression optimizer trains on the official training split.
The vectorizer and model are persisted together. The API returns a class,
positive probability, and weighted feature contributions. The static frontend
is responsive and intentionally black-and-white to keep the experiment and
explanation prominent.

## Evaluation and conclusions

The evaluation command computes accuracy, precision, recall, F1, and confusion
counts on the untouched test split. Full results are generated by the command
rather than invented in documentation. The design makes split handling and
preprocessing auditable, while the model's feature weights make a prediction
inspectable. Future work should reproduce the paper's binary/count/n-gram
comparisons and six model families in an environment with scikit-learn, then
report runtime and statistical variability.

## Reproducibility

`python3 -m cinescope.cli download`, `train`, `evaluate`, and `serve` provide
the complete path. Unit and API tests use fixtures, do not require a network,
and verify preprocessing, persistence, metrics, inference, and validation.
